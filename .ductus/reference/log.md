# log — reference

**Where a named section lives.** A section named below with no heading here is in the command file, `log.md`, with the numbered steps this file cites. A bare `§name` is a heading here or a constitution marker; one with another file's path on its line is a heading there, unless it is a constitution marker.

The run ends with the same report: the line that was added, the new total item count in the inbox, and the `/ductus:groom` pointer — and stops there.
