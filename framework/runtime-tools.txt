# Canonical names of runtime tools exposed by the `ductus` runtime.
#
# Source of truth: framework/constitution.md §runtime-boundary
#
# Each non-blank, non-comment line is one tool name (matching MCP tool names
# or runtime binary names). The list is consumed by:
#
#   - scripts/lint-tool-coverage.sh (requires every framework/commands/*.md
#                                     file naming one of these tools, or a
#                                     `# cli-only:` name, to carry the
#                                     §runtime-host-integration pointer)
#
# Tool names are case-sensitive exact-match strings. Names are bare
# `<verb>-<noun>` strings — server-level namespacing (`ductus`) is
# supplied by each host's MCP server registration, producing the
# host-specific wire identifier (Claude Code: `mcp__ductus__<verb>-<noun>`;
# Auggie / Antigravity: `mcp:ductus:<verb>-<noun>`; OpenCode: a
# `<server>_<tool>` name under the `ductus` prefix). Match the prefix
# rather than a spelling — the separator is a host detail, and a new host
# is one more spelling of the same namespace. The bare names are also the
# `ductus <name>` subcommand identifiers.
#
# A primitive the server does not serve is not a tool line. It is named on
# a `# cli-only:` line instead: a `ductus <name>` subcommand and a
# `ductus exec` step, never a tool. /audit's Family 9 reads those lines so a
# step naming one still counts as a primitive call, and runtime/tests/mcp.rs
# holds them equal to `CLI_ONLY_PRIMITIVES` (runtime/src/schema/registry.rs).
# `run-generator` runs any project file with `bash` (spec 022 task 14).
