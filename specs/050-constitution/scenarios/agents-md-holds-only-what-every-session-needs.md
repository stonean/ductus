# Agents-md-holds-only-what-every-session-needs

## Context

[075](../../075-agents-md-holds-what-every-session-needs/spec.md) narrows what `AGENTS.md` holds and defines the project's other files, and names this spec in its `cross-spec-impact:`, since this spec owns the constitution's text. §drift-prevention's *Shared knowledge stays in git* sent every learning true for this project alone to "its `AGENTS.md` or a rule file", which loads whole in every session, and the §spec-phase tree labelled `system.md`, `events.md` and `errors.md` with two or three words each.

## Behavior

- **Routing.** *Shared knowledge stays in git* routes a learning true for this project alone by 075's four-part test (*What AGENTS.md holds*) and names the homes 075's *Where everything else goes* lists. It says the added questions choose among the project's artifacts and never move a learning between population tiers (075 AC1). The population question stays first and unchanged.
- **Definitions.** The §spec-phase tree gives `system.md`, `events.md` and `errors.md` each a one-line definition matching 075's *What the other project files hold* (075 AC13). The tree is the definitions' canonical home; the template headers and `/prune`'s reference point at it.
- **The length rule's enforcement sentence.** The §text-first-artifacts length bullet ends "Nothing enforces this beyond `check-artifact-size`'s advisory read-size finding." Once the shipped hook refuses a commit that grows a project file past its limit (075 AC14), the sentence is reworded to name that refusal, in the change that lands the hook step; until then it is true.
- **This spec's own claims.** In the same change, every 050 artifact that equates the project tier with `AGENTS.md` is corrected: §Classification's table and `knowledge-routes-by-population-not-by-kind`'s unknown-population edge case. `artifacts-are-as-short-as-their-required-content` is rewritten where it stops holding: its *Existing artifacts are not swept* edge case excepts the four project files `/prune --project` walks, and its quoted bullet follows the reworded sentence.

## Edge Cases

- **The ceiling.** `framework/constitution.md` measured 49,993 bytes (`wc -c`, at `f9ea53dd`, 2026-10-29) against `scripts/lint-governing-size.sh`'s 50,000-byte ceiling. Each change measures what it adds and cuts at least as much in the same commit, dropping no required content and keeping verbatim every passage another spec quotes.
- **No copies.** The constitution states the test, the homes and the definitions once. The `ductus:memory-routing` block, the templates and `/prune`'s reference point at them (075), and this scenario points at 075 rather than restating its table.
